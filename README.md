# מחשבון מעטפת קו ראייה 360° כטב"מ – תחנה קרקעית (`uav-los-calculator`)

[![Deploy to Netlify](https://www.netlify.com/img/deploy/button.svg)](https://app.netlify.com/start/deploy?repository=https://github.com/peled2/uav-los-calculator)

אפליקציית **PWA** לחישוב וסרטוט **פוליגון טווח קו ראייה מירבי ב-360° (360° Viewshed / Max Range Envelope)** סביב תחנה קרקעית עבור כטב"מ עד טווח של **200 ק"מ**, מוכנה לפריסה ב-**Netlify**.

---

## עיקרי המימוש ההנדסי

1. **פוליגון מעטפת קו ראייה 360° (Viewshed Envelope)**:
   - כל לחיצה על המפה (או גרירת סמן התחנה) מציבה את התחנה הקרקעית ומחשבת אוטומטית את **פוליגון טווח ה-LOS המירבי בכל אזימוט ($0^\circ\text{–}360^\circ$)** עבור גובה המטוס שנבחר.
   - הפוליגון מוצג עם **מסגרת כפולה בולטת** (Halo כהה מתחת לקו ירוק/כתום זוהר ומילוי חצי-שקוף), לצד טבעות מרחק קונצנטריות (`50`, `100`, `150`, ו-$R_{\max}$ ק"מ).
   - **קרן בדיקה וחתך גבהים**: ריחוף סביב התחנה (או קליק ימני לנעילת קרן) מציג את קרן ה-LOS, מסמן את **הרכס החוסם**, ומאפשר פתיחת מגירה תחתונה מתקפלת עם חתך הגבהים המלא לאורך הקרן.

2. **מקור נתוני גובה – אריחי AWS Terrarium SRTM ב-Web Worker**:
   - טעינה ישירה של אריחי גובה לווייניים `https://s3.amazonaws.com/elevation-tiles-prod/terrarium/{z}/{x}/{y}.png` ב-`Web Worker` ללא תלות ב-REST API איטי:
     $$\text{elevation\_m} = (R \times 256.0 + G + B / 256.0) - 32768.0$$

3. **אלגוריתם Multi-LOD Max-Pooling + Hierarchical BVH Ray-Marching**:
   - **טווח קרוב (0 עד 15 ק"מ):** דגימת אריחי **Zoom 11** ברזולוציה של ~60 מטר.
   - **טווח ביניים ורחוק (15 עד 200 ק"מ):** בניית פירמידת **Max-Pooling** בת 4 רמות (`level0`, `level1` 2x2, `level2` 4x4, `level3` 16x16) על אריחי **Zoom 9** וסריקת קופסאות-על היררכיות לפי **כלל הברזל**:
     $$\alpha_{\text{upper}} = \frac{h_{\text{box\_max}} - H_0}{d_{\text{start}}} - \frac{d_{\text{start}}}{2 R_e}$$
   - **הפרדת פרופיל הקרקע מגובה המטוס (עדכון סליידרים ב-60 FPS):** שמירת מדרגות האופק (`ridges`) לכל קרן ופתרון אנליטי מהיר של משוואת הצל הריבועית:
     $$r_{\text{shadow}} = -R_e \alpha_j + \sqrt{(R_e \alpha_j)^2 + 2 R_e (H_{\text{UAV}} - H_0)}$$
   - **חישוב פרוגרסיבי:** ציור ראשוני של 360 קרניים ($1^\circ$) והשלמה ל-720 קרניים ($0.5^\circ$) עם עידון אדפטיבי ($0.25^\circ$) בגזרות עם קפיצות טווח חדות.

4. **ממשק מינימליסטי ומתקפל + שתי שכבות מפה בלבד**:
   - מפה מלאה (`100vw x 100vh`) ותפריט פרמטרים צף מתקפל בפינה הימנית העליונה (`צמצם ▴` / `הרחב ▾`).
   - **🗺️ מפה טופוגרפית:** `OpenTopoMap` יחד עם שכבת `Israel Hiking Map` בעברית.
   - **🛰️ מפת אורתופוטו:** `Esri World Imagery` יחד עם שכבת שמות יישובים וגבולות.
